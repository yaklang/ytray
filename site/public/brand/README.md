# YTray website artwork

These approved website assets intentionally complement, rather than replace,
the material application icon in `assets/app-icon/YTray.png`:

- `ytray-vector.svg`: compact navigation and footer identity.
- `ytray-flat.png`: prominent website hero identity.
- Material artwork: application and download surfaces via `/icon.png`.

The checksums in `SHA256SUMS` pin the supplied source artwork and are verified
by `script/verify-app-icons.py`.
