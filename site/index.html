把浏览器身份，
放回你的掌控。

YTray 把独立用户目录、HTTP 代理、调试端口与本地插件组织成清晰、可恢复的浏览器实例。适合安全测试、开发联调与多账号运营。

下载最新版 查看源代码

macOS 14+ · Windows 10/11 · 源码公开

01

身份真的隔离

Cookie、缓存、Local Storage、插件数据与登录态分别存放，不靠反复退出登录维持边界。

02

网络路径可见

直连和预设 HTTP 代理拥有不同入口；调试服务只绑定到 127.0.0.1。

03

历史可以恢复

停止后保留实例身份、用户目录、角标和最近页面，下一次继续同一个环境。

重要设置，不藏起来

登录系统后，YTray 已经在托盘等你。

安装版第一次启动会尝试默认开启开机启动，并明确告诉你结果。它只启动 YTray，不自动打开任何浏览器。侧栏和小组件都能控制；关闭前必须再次确认。

  • macOS 使用系统 Login Items
  • Windows 使用当前用户启动项
  • 失败不阻断其他功能，可随时重试

主操作台

高频动作，留在一块紧凑面板里。

从菜单栏或桌面边缘展开：编辑代理、检查连通性、查看缩略图、停止或恢复实例。开机启动状态就在右下角，不需要穿过多层设置。

同一个流程，保留明确边界

选择 → 启动 → 调试 → 恢复

  1. 选择浏览器使用本机 Chrome、Edge、Chromium，或安装 Chrome for Testing。
  2. 确定网络路径显式选择直连或已保存的 HTTP/HTTPS 代理。
  3. 创建独立实例分配用户目录、调试端口、插件与可辨认角标。
  4. 从历史继续恢复同一个身份环境，而不是重新创建一份配置。
